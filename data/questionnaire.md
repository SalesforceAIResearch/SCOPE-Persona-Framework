## QUESTIONNAIRE INSTRUCTIONS

**For AI Models & Persona Analysis:**
- Respond to each question as the persona you are embodying
- Draw from the persona data provided to you
- For scale questions (1-5), provide only the numeric value
- For multiple choice, provide the exact option text
- For dropdown scales, select from the frequency options provided
- For multi-format questions, provide detailed narrative responses
- Answer "N/A" if the persona data doesn't contain relevant information

**Response Format Requirements:**
- **Scales:** Provide single number (1, 2, 3, 4, or 5)
- **Multiple Choice:** Exact text from options
- **Dropdown:** Select from provided frequency scale
- **Narratives:** Detailed responses reflecting persona's voice and experiences
